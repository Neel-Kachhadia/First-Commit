# 45 — Codex Autonomy and Stop Rules

The coding agent is authorized to create the technical implementation required to reach the approved quality bar.

## Authorized autonomy

The agent may create:

- masks
- SVGs
- stamps
- seals
- texture derivatives
- roughness/normal maps
- film-strip systems
- pictograms
- procedural geometry
- transition utilities
- small shaders when justified
- debug routes/tools
- screenshot automation
- supporting components

Do not lower visual quality because an asset was not pre-supplied.

If an asset is missing:

1. determine exactly what the scene needs
2. create the minimal asset
3. integrate it
4. visually inspect it
5. iterate if needed
6. delete unused experiments

## What the agent may not invent

Do not invent:

- new KavachPay product claims
- live production integrations not supported by the brief
- new financial behavior for visual convenience
- humans or unrelated world-building
- a new art direction
- a new tech stack without a concrete repository constraint

## Stop and surface a question only when

- a required product claim is absent/ambiguous in the product brief
- a licensed font or protected brand asset is missing and cannot be substituted safely
- an external photographic source is essential but unavailable
- an existing repository constraint makes the locked architecture genuinely incompatible
- a change would delete or replace working user code beyond the landing-page scope

Do not stop merely because a technical asset is missing; create it.
