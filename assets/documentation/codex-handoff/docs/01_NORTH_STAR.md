# 01 — North Star

## One sentence

Build a landing page that feels like a **retro printed financial-control film assembled from mandates, passes, transaction slips, film strips, stamps, evidence frames, and typographic transitions**, where every major visual exists because of a real KavachPay behavior.

## The design equation

**KavachPay behavior -> cinematic idea -> visual execution**

Not:

**cool cinematic visual -> feature justification**

## What the visitor should feel

The page should feel authored, tactile, controlled, fast, and memorable without becoming a theme-park retro site.

The visitor should understand that KavachPay governs agentic money through:

- bounded mandates
- derived delegation
- allow / step-up / deny decisions
- human clearance when required
- stateful budgets
- lineage-aware revocation
- split-payment defense
- concurrency-safe consumption
- causal replay and evidence

The page should not feel like a feature tour. It should feel like a sequence of **product behaviors becoming cinema**.

## What makes this different

The visual identity is not “AI finance.”

It is not “1970s computers.”

It is not “retro futurism.”

It is not “film grain on a fintech site.”

The identity comes from combining:

1. **KavachPay-specific scenarios** that competitors cannot reuse unchanged.
2. **Retro editorial/film-prop graphic design**.
3. **Transition choreography** that reflects each scenario's behavior.
4. **Physical print language** instead of generic digital cards.

## The cast

There are no human characters.

The “cast” is:

- mandate sheets
- authority passes
- transaction slips
- approval/clearance artifacts
- stamps
- film frames
- evidence strips
- budget numerals
- merchant/category marks
- icons
- rules, arrows, registration marks, perforations

## Visual principle

Specific before beautiful.

Product-specific before cinematic.

Transitions before 3D.

Typography before decoration.

Restraint before spectacle.
