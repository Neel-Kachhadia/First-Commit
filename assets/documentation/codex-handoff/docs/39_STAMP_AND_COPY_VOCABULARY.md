# 39 — Stamp and Decision Vocabulary

Use a small, consistent administrative vocabulary.

## Primary stamp phrases

```text
APPROVED
DENIED
HOLD FOR CLEARANCE
REVOKED
RESERVED
BLOCKED
ONE ECONOMIC ACTION
```

## Supporting approval language

```text
REFER FOR APPROVAL
CLEAR ONCE
DECLINE
```

## Style

Stamps should feel physically applied:

- deep administrative red for warning/hold/revoke/block actions
- restrained approval colour where the board calls for it
- slightly imperfect ink coverage
- small rotation or registration variation
- subtle edge breakup
- no decorative “grunge font” treatment

Create clean SVG masters plus optional procedural distress masks.

Do not bake critical copy into AI-generated photographs.
