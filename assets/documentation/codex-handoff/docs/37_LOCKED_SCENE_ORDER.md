# 37 — Locked Scene Order

The landing page is a cinematic product story, not a conventional SaaS marketing template.

## Locked sequence

```text
00  OPENING / HERO
01  MANDATE
02  ALLOW / STEP-UP / DENY
03  DELEGATION
04  STEP-UP CLEARANCE
05  REVOCATION
06  SPLIT-PAYMENT DEFENSE
07  BUDGET / CONCURRENCY
08  CAUSAL REPLAY
09  CLOSING
```

Do not insert generic sections such as:

- Features grid
- Testimonials
- Pricing
- Customer logos
- FAQ
- Generic CTA band
- “Why us” cards

unless explicitly requested later.

## Scene purpose

### 00 — Opening / Hero

Establish the KavachPay physical-film language and the idea of bounded autonomous money authority.

### 01 — Mandate

Show intent becoming deterministic financial authority.

### 02 — Allow / Step-Up / Deny

Show three requests resolving through three different cinematic grammars.

### 03 — Delegation

Show derived authority being carved from parent authority without creating new capacity.

### 04 — Step-Up Clearance

Show a high-value action held for one-time approval using the formal clearance artifact.

### 05 — Revocation

Show dependent authority stopping while an unrelated branch continues.

### 06 — Split-Payment Defense

Show separate smaller requests correlating into one economic action.

### 07 — Budget / Concurrency

Show two actions competing for the same final remaining budget and only one succeeding.

### 08 — Causal Replay

Spatial climax. Reconstruct a completed action through its causal layers.

### 09 — Closing

Return to a restrained, crisp brand/product statement. Do not try to out-spectacle Replay.
