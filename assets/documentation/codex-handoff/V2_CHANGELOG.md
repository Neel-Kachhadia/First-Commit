# v2 Change Log — Physical Stage + Asset System

This revision updates the original implementation handoff with the approved lightweight 3D strategy.

## What changed

- 3D is now explicitly approved as a **physical film-compositing stage**.
- Geometry remains primitive: paper planes, film strips, receipts, tickets, shallow bends.
- One shared WebGL renderer/canvas is preferred.
- Mandate, Delegation, Step-Up, Revocation, Split-Payment and Concurrency receive restrained depth.
- Causal Replay becomes the single major spatial 3D climax.
- Asset craft, typography, film language and transitions remain the dominant workload.
- Added a 30–50 item KavachPay Master Physical Asset Pack specification.
- Added exact asset-generation/sourcing briefs and per-scene asset mapping.
- Added renderer/camera/material/DPR/fallback technical specifications.
- Updated page architecture, performance, component structure, transitions, motion, implementation plan and QA gates.

## Unchanged rules

- no humans
- no cities/unrelated world-building
- no historical computers
- no cyberpunk
- no decorative 3D hero objects
- product behavior first
- final reference board remains canonical
