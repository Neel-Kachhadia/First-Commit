# 02 — Source of Truth and Precedence

There were multiple exploratory directions before the final board. This file prevents the implementation agent from accidentally resurrecting rejected ideas.

## Precedence order

When two instructions conflict, use this order:

1. `source/KavachPay_Final_Visual_Reference.png`
2. `AGENTS.md`
3. This implementation bible
4. `source/KavachPay_Product_Brief.html`
5. Earlier conceptual notes only when they do not conflict with 1–4

## Final visual direction

The accepted reference board contains eight product-native panels using:

- black board/background
- ivory paper
- serif KavachPay branding
- condensed uppercase section headings
- torn/perforated paper edges
- film-strip framing
- tickets and passes
- stamped outcomes
- sparse red, green, and yellow state colors
- retro print imperfections
- simple pictograms
- no human imagery

## Superseded ideas — do not implement

The following were explored and rejected or superseded:

- humans as protagonists
- faces, hands, silhouettes, human lifestyle scenes
- “city that shops by itself”
- breakfast scenes
- generic autonomous-commerce world-building
- futuristic cities
- giant architecture or control chambers
- authority as a literal law of physics
- historical computers / vintage terminals
- retro-futuristic computer rooms
- giant floating modern SaaS cards
- modern UI interruption as the dominant step-up language
- a single ₹649/₹679 transaction as the whole site protagonist
- one master physical metaphor for every feature
- heavy 3D as the primary visual system

## Final Step-Up interpretation

The accepted Step-Up block is **retro clearance paperwork**, not a contemporary SaaS modal.

Canonical copy/visual hierarchy:

- `TRAVEL AGENT`
- `₹4,900`
- `AUTOMATIC LIMIT ₹3,000`
- red `HOLD FOR CLEARANCE`
- secondary `REFER FOR APPROVAL`
- `CLEAR ONCE`
- `DECLINE`

## Final technology stance

The landing page is **transition-first and 3D-light**, not flat-only.

A lightweight shared WebGL stage is approved for physicalizing KavachPay artifacts using primitive planes, shallow Z depth, parallax, shadows, small paper bends and deliberate camera motion.

The baseline rule is:

> **Use 3D as a physical film-compositing stage, not as a world-building system.**

Causal Replay is the one scene where deeper spatial choreography is expected.

Do not use complex modelling, multiple heavy canvases, decorative 3D, or generic fintech WebGL objects.
