# 42 — Typography Rules

Typography is part of the spectacle and must not be treated as text placed over visual effects.

## Maximum family count

Use at most:

1. one expressive serif display family
2. one condensed administrative sans family
3. one utilitarian supporting sans/mono only if genuinely required

Do not introduce a new typeface per scene.

## Font assets

If licensed font files are supplied, use local WOFF2 and respect their license.

If the exact families are not yet supplied, keep typography tokens abstract and do not silently lock the project to generic SaaS defaults.

## Roles

### Display serif

Used for:

- KavachPay brand moments
- major film-title language
- selected large editorial headlines

### Condensed administrative sans

Used for:

- stamps
- clearance labels
- ticket fields
- transaction metadata
- frame numbers
- document headings

### Utility sans/mono

Used sparingly for:

- evidence details
- hashes
- provider references
- timestamps

## Large type as visual event

Important product states may become near-full-screen compositions:

```text
₹500
₹0
REVOKED
WHY?
```

These are designed frames, not ordinary headings.

## Legibility

Print texture and grain may never reduce critical amounts, decision labels, or product logic below reliable readability.
