# 35 — Creative Lock

This document is a hard creative constraint. It exists to prevent long autonomous implementation sessions from drifting away from the approved direction.

## Governing equation

**KavachPay behavior -> cinematic idea -> visual execution**

Never:

**cool visual -> search for a KavachPay feature to justify it**

Every major scene must answer:

> What specifically does KavachPay do that causes this scene to exist?

If the answer is only “AI commerce,” “the future,” “autonomous agents,” or “machine economy,” reject the scene.

## The theme

The website uses the language of a **lost late-1970s speculative film about autonomous commerce**.

1978 controls:

- cinematography
- film response
- editing
- typography
- print language
- physical props
- sound grammar
- production-design restraint
- optical / practical-effects thinking

1978 does **not** control the imagined technology.

The film is retro. KavachPay itself is not obsolete technology.

## Absolute exclusions

### No humans

No:

- people
- faces
- hands
- bodies
- silhouettes
- crowds
- human portraits
- human-shaped figures
- lifestyle photography

The product artifacts, states, typography, documents, receipts, film strips, and transitions are the cast.

### No obsolete-computer retro

No:

- CRTs
- vintage computers
- tape reels
- punch cards
- telephone switchboards as computation metaphors
- green terminals
- old server rooms
- analog-control-panel fetishism
- Cold War/NASA computer rooms
- steampunk/dieselpunk machinery

### No unrelated world-building

No:

- city skylines
- speculative mega-cities
- lifestyle scenes
- random architecture
- generic airport drama
- generic shopping scenes
- generic “future of commerce” environments

A scene that would still work unchanged after removing KavachPay is probably wrong.

### No generic AI / fintech visual language

No:

- floating glass cards
- holograms
- glowing node networks
- generic dark sci-fi rooms
- wet reflective floors
- volumetric god rays as default cinema
- random particles
- giant 3D coins/cards/shields/locks
- robots
- chrome luxury objects
- modern SaaS-card composition used as the visual identity

## Core visual identity

- near-black field
- warm ivory paper family
- restrained deep administrative red
- occasional subdued approval/denial accent when needed
- institutional print
- receipt stock
- authority passes
- mandate sheets
- stamps
- film strips
- evidence records
- contact-sheet grammar
- editorial typography
- physical shadows
- print imperfections
- selective film grain
- hard cuts
- masks
- practical/composited physical depth

## 3D rule

3D is **invisible craftsmanship**.

The user should notice:

- depth
- parallax
- lighting
- focus
- paper presence
- camera movement

The user should not primarily notice:

- “a 3D model”
- complex geometry
- WebGL tricks

Causal Replay is the exception where spatial depth is allowed to become a major climax.

## Product-native scene anchors

Strong anchors include:

- bounded authority being compiled from intent
- ALLOW / STEP-UP / DENY resolving differently
- child authority derived from parent authority without amplification
- a high-value action pausing for one-time clearance
- parent revocation invalidating dependent descendants while unrelated authority continues
- repeated smaller requests resolving into one economic action
- two requests competing for the final remaining budget
- a completed decision being reconstructed causally

## Final filter

For every major frame ask:

1. **Product test:** Which KavachPay behavior generated this visual?
2. **Cinema test:** Is the behavior expressed through filmmaking/editorial language rather than a software diagram?
3. **Necessity test:** Could another fintech brand replace the logo and keep this scene unchanged?

If #1 is vague, #2 is no, or #3 is yes, redesign.
