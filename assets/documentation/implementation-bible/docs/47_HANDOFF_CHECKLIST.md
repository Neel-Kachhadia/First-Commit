# 47 — Handoff Checklist

Before launching the coding agent, provide the following.

## Required non-image files

- this full implementation bible
- `AGENTS.md` copied to repository root
- original KavachPay product brief
- existing project repository, or permission to initialize Next.js
- licensed font files / names if already selected

## Required user-supplied visual references

The user supplies these separately; they are not regenerated by Codex:

- approved KavachPay master visual board
- PAPER_01_MASTER_IVORY_4K
- PAPER_02_HANDLED_AUTHORITY_4K
- PAPER_03_THIN_RECEIPT_4K
- PAPER_04_TICKET_STOCK_4K
- PAPER_05_OFFICIAL_DOCUMENT_4K

## Instructions to the agent

```text
Read AGENTS.md first.
Read MANIFEST.md second.
Read docs/00_README.md third.
Then follow the documented read order.
Do not begin implementation before reading the creative lock, locked stack, quality rule, scene order, asset policy, and master build prompt.
```

## Do not manually pre-create

Codex should create these only when scenes need them:

- torn edge masks
- perforation masks
- stamps
- seals
- film strips
- grain/dust overlays
- halftone
- print misregistration
- paper roughness/normal maps
- film roughness maps
- shadow sprites
- SVG pictograms
- receipt/document components
- authority-pass components
- replay strips

## Repository baseline

If an existing repository is provided, Codex should first:

1. inspect its package manager
2. run the current build/tests
3. identify the landing-page route
4. inspect existing fonts/styles
5. take a baseline screenshot
6. avoid unnecessary architecture rewrites

## Completion deliverables

The agent must report:

- route implemented
- files changed
- dependencies added/removed
- generated assets and scripts
- Playwright checkpoint screenshots per scene
- desktop/mobile behavior
- reduced-motion behavior
- no-WebGL fallback
- performance observations
- remaining visual mismatches
- any product claims intentionally omitted
