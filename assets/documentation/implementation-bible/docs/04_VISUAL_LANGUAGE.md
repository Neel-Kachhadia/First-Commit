# 04 — Visual Language

## Reference

Open `source/KavachPay_Final_Visual_Reference.png` before implementing any scene.

The goal is not to reproduce the board as a static 4x2 grid. The goal is to make its visual language **move through the page**.

## Core aesthetic

Think:

- retro editorial finance
- printed institutional artifacts
- film/contact-sheet composition
- tactile paper
- high-contrast black board
- controlled state stamps
- cropped typography
- perforated/torn edges
- physical registration marks
- sparse, meaningful color
- subtle film/print imperfection

Do not think:

- retro computer
- cyberpunk
- 3D environment
- modern SaaS
- vintage scrapbook
- detective corkboard
- luxury editorial
- generic “old paper” website

## Background

Primary environment is near-black with fine texture. It should feel like a board, print field, or dark film stock—not a glossy app background.

Do not add gradients simply to create depth.

## Paper

Paper is warm ivory / aged cream, but not dirty beige.

Texture should be subtle enough that copy remains crisp.

Edges can be:

- torn
- deckled
- ticket-perforated
- straight-cut

Use variation intentionally by scene.

## Ink

Black ink should be deep but imperfect.

Red is intervention / revocation / clearance / block.

Green is approved.

Yellow/ochre is allow/attention labeling.

Color is semantic, not decorative.

## Typography

Three-role system:

1. **Brand/display serif** — KavachPay wordmark and occasional major display moments.
2. **Condensed uppercase grotesk** — section numbering, operational labels, stamps, panel names.
3. **Neutral mono/sans detail face** — timestamps, IDs, small metadata, technical evidence.

Avoid using a typewriter font everywhere. That is a retro shortcut.

## Iconography

Icons should feel like simple printed pictograms:

- shopping basket
- delivery scooter
- airplane
- merchant/category marks
- decision/evidence symbols

No 3D icons. No glossy icons. No emoji.

## Texture

Use texture in layers:

- global subtle black-stock noise
- paper-fiber texture
- localized stamp ink breakup
- film-strip dust only where film framing exists
- tiny registration imperfections

Do not place the same grain overlay at high opacity across everything.

## Framing

The board uses rectangular editorial framing, film-strip cells, passes, receipts, and large paper artifacts.

The landing page should alternate between:

- full-viewport composition
- centered artifact
- split-screen / triptych
- film-strip band
- oversized numerical typography
- diagonal replay strip

Variation is required, but all scenes should feel like one graphic department made them.
