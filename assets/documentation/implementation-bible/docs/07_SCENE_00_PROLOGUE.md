# 07 — Scene 00: Prologue / Brand

## Product purpose

Introduce KavachPay as the system whose rules will drive the following sequences.

Do not attempt to explain the full product in the opening.

## Visual composition

Start nearly black.

Reveal the `KavachPay` wordmark in large ivory serif typography.

Small supporting copy:

`CONTROL TRAVELS FURTHER`

Opposite edge or later beat:

`SAME MONEY.`
`A SAFER TOMORROW.`

## Transition choreography

1. Black field with very subtle stock texture.
2. Wordmark appears through an optical exposure reveal, not a fade-up opacity alone.
3. Small copy registers in with slight print misalignment that resolves.
4. A thin ivory rule draws across the viewport.
5. The rule becomes the top rule of the Mandate scene.
6. The next scroll beat reveals paper fiber beneath the rule.

## Implementation

DOM + CSS only.

Use:

- masked reveal for wordmark
- pseudo-element texture
- GSAP timeline for rule transformation

No 3D.
